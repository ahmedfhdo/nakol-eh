# Nakol Eh (ناكل ايه)

Offline-first PWA that picks a random dinner from the protein categories you have at home.
See `CLAUDE.md` for the full spec and build order.

```bash
npm install
npm run dev      # dev server (no service worker)
npm test         # unit tests (Vitest)
npm run check    # type-check (svelte-check + tsc)
npm run build    # production build into dist/
npm run preview  # serve dist/ — use this to test offline mode and install
```

The service worker is only generated by `npm run build`, so test offline/install with
`npm run build && npm run preview`. In Chrome DevTools → Application you can see the
manifest, the service worker, and toggle "Offline".
